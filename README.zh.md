# 眼见为实

## 简介

**《眼见为实》** 是由林林解说ange开发的一款独立游戏。
本项目是使用Godot4.7游戏引擎开发的。

## 免责声明

1. 本项目旨在用于个人学习和交流，而非商业目的。
2. 如有建议或想反馈漏洞，请提交 issue .
3. 如有其他问题，请发邮件至Linlinange@163.com.
